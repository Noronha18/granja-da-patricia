# DM Sans

Self-hosted unmodified WOFF2 variable font, normal style, weights 400–700. Downloaded 2026-10-29 from Google Fonts. Latin and Latin Extended subsets are selected by unicode-range; Portuguese accents are included in Latin.

Sources:
- https://fonts.googleapis.com/css2?family=DM+Sans:wght@400..700&display=swap
- https://fonts.gstatic.com/s/dmsans/v17/rP2Yp2ywxg089UriI5-g4vlH9VoD8Cmcqbu0-K4.woff2
